

# 🚀 CareerTrack – Job Application Tracker

CareerTrack is a modern and responsive job application management web application built using **HTML, CSS, and Vanilla JavaScript**.

The application helps job seekers organize their applications, monitor interview progress, manage offers, and analyze their job search with a clean and intuitive dashboard.

---

## ✨ Features

- 📊 Interactive Dashboard
- 💼 Manage Job Applications
- 📝 Add, Edit & Delete Applications
- 🔍 Search & Filter Jobs
- 📅 Interview Tracker
- 📈 Career Analytics
- 🌙 Dark / Light Mode
- 💾 Local Storage Support
- 📱 Fully Responsive Design
- 🎨 Modern UI/UX
- ⚡ Fast Performance
- 🔔 Toast Notifications

---

## 🛠 Tech Stack

- JavaScript (ES6+)
- Local Storage API
